# Dáreje — инструкции для всех чатов проекта

## Обязательное правило GitHub

- Пользователь поручил после каждого завершённого изменения проекта делать коммит и отправлять его в https://github.com/bekw-eg/Dareje (origin, ветка main).
- Это постоянное разрешение на обычные commit и push в рамках запрошенных изменений. Повторное подтверждение у пользователя не требуется; ограничения среды и проверки разрешений необходимо соблюдать.
- Автор и коммитер — только пользователь: `bekw-eg <zdeathbecaqso716@gmail.com>`. Не добавлять других авторов, Co-authored-by или подписи об авторстве ИИ.
- Перед коммитом проверить изменения и выполнить подходящие проверки. Не включать секреты, локальные настройки, кеши и результаты сборки.
- Не использовать force push и не перезаписывать чужую историю. При блокировке отправки сообщить пользователю причину; не заявлять об успешном push без подтверждения.
- В конце кратко сообщить результат и идентификатор отправленного коммита.

## Предпочтения пользователя

- Название приложения: **Dáreje**.
- Общаться по-русски; интерфейс приложения — на казахском языке.
- Менять файлы непосредственно в проекте. Не вставлять исходный код и полные файлы в чат, если пользователь отдельно не попросит. Ответы должны быть краткими.
- Продолжать существующий Flutter-проект, не пересоздавать его.
- Выполнять только явно запрошенную фазу. Не переходить к следующим фазам самостоятельно.
- Сохранять простой, понятный студенту код. Не добавлять библиотеки и сложную архитектуру без необходимости.

## Текущее состояние

- Выполнены базовый интерфейс с Material 3, локальная регистрация и вход по логину или почте.
- Регистрация сохраняет логин, имя, фамилию, почту и хеш пароля с солью; пароль — минимум 8 символов с буквами или цифрами. Логин допускает латинские буквы, цифры и дефис.
- Аккаунты и сессия сохраняются на устройстве / в текущем браузере. После перезапуска вход восстанавливается; кнопка «Шығу» завершает только сессию. Тестовая пара `student@test.kz` / `123456` удалена.
- Firebase, реальная авторизация, достижения, рейтинг, профиль и админ-панель ждут отдельных заданий пользователя. Существующие вкладки-заглушки сохранять.
- Обновлять этот раздел при выполнении следующих запрошенных фаз.
